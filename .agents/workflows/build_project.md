# Build Project Workflow

Execute these steps to build the locally exported project:

1. **Install Dependencies**
   Run the following command to make sure all npm dependencies are installed:
// turbo
   ```bash
   npm install
   ```

2. **Build the NextJS project**
   Compile and set up the production bundle:
// turbo
   ```bash
   npm run build
   ```
