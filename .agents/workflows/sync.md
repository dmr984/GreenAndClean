---
name: Sync Project
description: Automatically stage, commit, and push changes to GitHub.
---

# Step 1: Stage changes
// turbo
Run `git add .` to stage all modifications.

# Step 2: Commit changes
// turbo
Run `git commit -m "Auto-sync: %DATE% %TIME%"` (or a descriptive message).

# Step 3: Push changes
// turbo
Run `git push` to upload everything to GitHub.
